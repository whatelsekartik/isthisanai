Cadence — a 1.5M-parameter language model that runs int8 on one serverless vCPU

Trained from random initialisation on public-domain books. No pretrained weights, no external model API, no GPU — the forward pass below runs in this function's Node.js process. Weights are int8; the recurrent state is an Int32Array and the per-token decay is an exact bit shift (power-of-two retention), so the recurrence needs no floating point at all.

This is a research artefact: 1.5M parameters and ~4.6M training tokens on two CPU cores. It emits period-flavoured English, not usable prose. The contribution being demonstrated is the cost of inference — exact integer recurrence, 3 MB of int8 weights, 216 KB of state — not the eloquence. See docs/ for the literature review, the design, the transformer baseline at the same token budget, and the measured limitations.
